# Kasfbi Abool Jayah — Liquid Glass Portfolio

Cinematic, responsive static portfolio for Kasfbi Abool Jayah (SLIIT IT undergraduate). Made with HTML, CSS and vanilla JavaScript — no framework or build needed.

## Features
- Liquid-glass panels, neon aurora backgrounds, morphing 3D shapes, jelly buttons
- Scroll reveals, parallax tilt, animated project visuals and a playful runaway button
- Responsive navigation and reduced-motion accessibility
- Verified GitHub repository links, projects, skills and public certificate list
- CV web page at [cv.html](cv.html), printable to PDF

## Publish on GitHub Pages
Go to repository Settings → Pages. Under Build and deployment, choose Deploy from a branch. Select main and / (root), then Save.

Expected Pages URL: https://it24102666.github.io/potfolio-new/

## Update portrait
The live site currently uses an externally hosted portrait from the existing ChatGPT Site, falling back to the previous GitHub photo. For a fully self-contained site, upload the newly generated professional portrait to assets/professional-portrait.jpg, then set the img src in index.html to assets/professional-portrait.jpg.
